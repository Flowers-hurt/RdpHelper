# 安全策略 / Security Policy

RdpHelper 会修改远程桌面、SSH 和防火墙设置，安全问题我们会优先处理。
RdpHelper changes Remote Desktop, SSH and firewall settings, so security issues get top priority.

## 支持的版本 / Supported versions

只为最新发布版本提供安全修复。/ Only the latest release receives security fixes.

## 报告漏洞 / Reporting a vulnerability

请**不要**公开提 Issue。请通过 GitHub 的 [私下报告漏洞](https://github.com/Flowers-hurt/RdpHelper/security/advisories/new) 提交，附上影响版本、复现步骤和可能的影响。
Please **do not** open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/Flowers-hurt/RdpHelper/security/advisories/new) with the affected version, steps to reproduce and impact.

我们会尽快确认并在修复发布后致谢报告者。/ We will acknowledge the report and credit you once a fix is released.
